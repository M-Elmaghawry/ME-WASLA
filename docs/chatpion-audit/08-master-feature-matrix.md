# 08 — المصفوفة المرجعية الكاملة للميزات

تاريخ التدقيق: **29 أكتوبر 2026**. هذه **223 قدرة وظيفية مميزة بمعرف Canonical ID**. كل الصفوف ناتجة عن فحص ساكن؛ **لا توجد ميزة VERIFIED_OPERATIONAL ولااختبار Runtime ناجح**. عمود Runtime Verification يحدد الاعتماد أوالتحقق التالي، وليس نتيجة نجاح. القيود العامة في [01](01-project-architecture.md) والمخاطر في [07](07-security-and-readiness.md) تنطبق حتى على CANDIDATE_AFTER_TESTING.

## قواعد التصنيف والعد

- IMPLEMENTED_IN_SOURCE: مسار معالجة جوهري موجود؛ لا حكم على التوافق الخارجي أوالأمان أوالتفعيل.
- PARTIALLY_IMPLEMENTED: جزء حقيقي مع فجوة أوبوابة إضافة غائبة أوحد جوهري.
- ADDON_PRESENT: الحزمة الفيزيائية موجودة؛ registration/active/license مجهولة.
- ADDON_NOT_FOUND: حزمة مطلوبة غير موجودة؛ قد توجد hooks ومستهلكات.
- INTEGRATION_STUB_ONLY: أسماء أودالة فارغة/معلقة دون مسار end-to-end.
- NOT_FOUND: لا تنفيذ متكامل معثور في النطاق المحدد؛ UNDETERMINED: الدليل لا يكفي لحسم الميزة.
- تجمع Code Status إلى الإجمالي دون تداخل؛ Marketing Readiness تصنيف مستقل لا يضاف إليه. جرد الحزم في 03 وحدة عد مختلفة ولايضاف إلى عدد الميزات.
- الميزة العابرة للتصنيفات سجلت مرة واحدة: DM البوت في A03، نشر Instagram في C04–C06، استيراد/تقسيم جهات اتصال SMS والبريد في G02/G03، تقارير الحملات في B09/F07/G05/H14، وإيراد المتجر I29 مقابل اشتراكات المنصة J08. الإحالات في 02 لا تضيف ميزات.
- عناوين قدرات متقاربة قد تمثل أسطح استخدام مختلفة، مثل إدارة الوسوم A25 وإتاحتها داخل المحادثة D04؛ لا تمثل عدد محركات برمجية مستقلة.
- عدد «تحتاج إعدادًا خاصًا» محسوب للصفوف ذات code I/P/A/S واعتماد غير BASE/LOCAL فقط؛ إعداد DB العالمي مطلوب للجميع ومستبعد من هذا العداد. لا يمثل العدد تفعيلًا مثبتًا.
- Source Module/Evidence يذكر الملف أوصفحة سجل البحث مع اسم دالة أوحقل أوجدول. reference code في الملاحظات يشير إلى مسار ثانوي مذكور بمفاتيح الأدلة أدناه، دون افتراض تحميله دائمًا.

| --- | --- |
